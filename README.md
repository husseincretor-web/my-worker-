# متجر إلكتروني عربي — المرحلة الأولى (Backend Core)

هذه **المرحلة الأولى فقط** من المشروع الكامل. تشمل:
- البنية التحتية (Cloudflare Workers + D1 + R2)
- قاعدة البيانات الكاملة (كل الجداول المطلوبة، جاهزة للمراحل القادمة)
- نظام مصادقة كامل (عملاء + أدمن) بتشفير كلمات مرور آمن (PBKDF2) و JWT
- إدارة التصنيفات والمنتجات (عرض عام + CRUD كامل للأدمن)
- إدارة الإعدادات العامة للمتجر

**غير مكتمل بعد** (المراحل القادمة): السلة، الطلبات، الدفع اليدوي وإثباته، الخدمات، الحجوزات، تحميل المنتجات الرقمية، لوحة تحكم الأدمن (واجهة)، واجهة المتجر (واجهة)، SEO الكامل.

---

## 1) المتطلبات

- حساب Cloudflare مجاني: https://dash.cloudflare.com/sign-up
- Node.js 18 أو أحدث مثبت على جهازك.

## 2) التثبيت المحلي

```bash
cd store
npm install
npx wrangler login
```

سيفتح المتصفح لتسجيل الدخول وربط جهازك بحساب Cloudflare.

## 3) إنشاء قاعدة البيانات D1 (مجانية)

```bash
npx wrangler d1 create arabic-store-db
```

سيعطيك الأمر `database_id`. افتح `wrangler.toml` وضعه مكان:
```
database_id = "PUT-YOUR-DATABASE-ID-HERE"
```

## 4) إنشاء تخزين الملفات R2 (مجاني حتى 10GB شهريًا)

```bash
npx wrangler r2 bucket create arabic-store-files
```

## 5) تشغيل قاعدة البيانات (الجداول + البيانات الأولية)

محليًا للتجربة:
```bash
npm run db:migrate:local
npm run db:seed:local
```

على الخادم الفعلي (بعد أن تكون جاهزًا للنشر):
```bash
npm run db:migrate:remote
npm run db:seed:remote
```

## 6) إعداد الأسرار (Secrets) — لا تضعها أبدًا داخل الكود

```bash
npx wrangler secret put JWT_SECRET
```
سيطلب منك إدخال قيمة — استخدم نصًا عشوائيًا طويلًا وقويًا (32 حرفًا فأكثر).

## 7) إنشاء حساب الأدمن الأول

```bash
node scripts/create-admin.mjs "اسمك الكامل" admin@example.com "كلمة-مرور-قوية123"
```

سيطبع لك أمر `wrangler d1 execute` جاهزًا — انسخه ونفّذه كما هو.

## 8) التشغيل محليًا للاختبار

```bash
npm run dev
```

ثم جرّب:
```bash
curl http://localhost:8787/api/health
curl -X POST http://localhost:8787/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"full_name":"أحمد","email":"test@test.com","password":"test1234"}'
```

## 9) النشر الفعلي (Deploy)

```bash
npm run deploy
```

سيعطيك رابطًا مثل: `https://arabic-store-api.YOUR-SUBDOMAIN.workers.dev`
هذا هو رابط الـ API الخاص بمتجرك — مجاني بالكامل ضمن الحدود المجانية.

## ماذا قد يحتاج دفعًا مستقبلًا؟ (كما طلبت، بدون أي دفع تلقائي مخفي)

| البند | هل هو مجاني؟ |
|---|---|
| Cloudflare Workers | مجاني حتى 100,000 طلب/يوم |
| Cloudflare D1 | مجاني حتى 5GB وحدود قراءة/كتابة يومية سخية |
| Cloudflare R2 | مجاني حتى 10GB تخزين + مليون عملية قراءة/كتابة شهريًا |
| **دومين خاص** (مثل mystore.com) | **مدفوع** (حوالي 8-15$ سنويًا) — يمكنك تجاهله والعمل على رابط `workers.dev` مجانًا |
| **بوابة دفع إلكتروني** (فيزا/ماستركارد لاحقًا) | **مدفوعة** — عمولة على كل عملية، لم تُفعّل في هذا المشروع إطلاقًا حسب طلبك |
| **رسوم تحويل بنكي** | يدوي بالكامل حاليًا، بدون أي API — لا تكلفة |
| **SMS للتحقق أو الإشعارات** | **مدفوعة** إن أردتها — لم تُستخدم هنا |
| **WhatsApp API الرسمي** | **مدفوع** — لم نستخدمه؛ اعتمدنا رابط `wa.me` المجاني بدلاً منه (سيُضاف في مرحلة الواجهة) |
| **إرسال بريد إلكتروني** (تأكيد الحساب، استعادة كلمة المرور) | معظم الخدمات المجانية محدودة جدًا (100 بريد/يوم أو أقل) — سأخبرك بالخيارات عند الوصول لهذه المرحلة ولن أفعّل شيئًا مدفوعًا دون إخبارك |

## ملاحظة أمنية مهمة حول تحديد المحاولات (Rate Limiting)

الحل الحالي في الكود بسيط (يعمل داخل كل نسخة Worker على حدة). للحماية الأقوى على مستوى الحساب كاملًا، يمكنك لاحقًا تفعيل ميزة **Cloudflare Rate Limiting Rules** المجانية جزئيًا من لوحة Cloudflare مباشرة (Security → WAF).

## هيكل المشروع الحالي

```
store/
├── wrangler.toml          # إعدادات Cloudflare
├── package.json
├── tsconfig.json
├── migrations/
│   ├── 0001_init.sql      # كل الجداول (users, orders, products...)
│   └── 0002_seed.sql      # بيانات أولية (إعدادات + طرق دفع)
├── scripts/
│   └── create-admin.mjs   # إنشاء حساب أدمن بأمان
└── src/
    ├── index.ts           # نقطة الدخول + التوجيه
    ├── types.ts           # أنواع Bindings
    ├── lib/
    │   ├── password.ts    # تشفير كلمات المرور PBKDF2
    │   ├── jwt.ts          # توليد/تحقق JWT
    │   └── validate.ts    # تحقق من المدخلات
    ├── middleware/
    │   └── auth.ts        # حماية المسارات + rate limiting
    └── routes/
        ├── auth.ts         # تسجيل / دخول / أدمن / تغيير كلمة المرور
        ├── categories.ts   # التصنيفات
        ├── products.ts     # المنتجات (بحث، فلترة، CRUD)
        └── settings.ts     # إعدادات المتجر
```
